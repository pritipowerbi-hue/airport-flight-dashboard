
# Airport & Flight Dashboard

Power BI dashboard for airport and flight data analysis (2025).

![Dashboard](Screenshot%202026-10-22%20142814.png)

## Data
- FactFlights: flight details
- DimAirline, DimAirport, DimDate: dimension tables

## Tools
Power BI, Excel, DAX

## How to open
Download the .pbix file and open it in Power BI Desktop.
